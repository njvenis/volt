# Security policy

VOLT RC1 is available for evaluation and is not intended for production deployment.

## Report a vulnerability privately

[Report a vulnerability through GitHub](https://github.com/njvenis/volt/security/advisories/new). Private vulnerability reporting is enabled for this public repository. Sign in to GitHub and use **Security → Report a vulnerability**.

Do not disclose sensitive findings in public issues, pull requests or discussions. If the private reporting route is unavailable, contact the maintainer through an already-established private channel to arrange a secure route; do not include the finding in a public request.

Include the affected release and source revision or image digest, impact, and a minimal reproduction using synthetic data. Do not attach secrets or production records. For RC1, identify `0.1.0-rc.1` and the exact artifact used; release details are on the [release page](https://github.com/njvenis/volt/releases/tag/v0.1.0-rc.1).

Security reports are reviewed on a best-effort basis. No response-time or remediation SLA is offered. Publication of RC1 does not establish a long-term maintenance commitment or production-readiness guarantee.
