# Compose primary installation

## Why

Provide a source-free installation path for the existing supervised VOLT image, with an explicit labelled local demo and a separate external OIDC configuration for evaluation.

## Scope

Package Compose files, setup tooling, non-secret examples, lifecycle and coordinated backup/restore instructions. Preserve the single image, three persistent stores, existing recovery controls and API-only DefectDojo boundary. Local verification is disposable and does not claim named-provider, cloud or production readiness.

## Requirements

NFR-04, NFR-05, NFR-06, CR-01, CR-03, CR-05, CR-08, CR-09, CR-10, CR-11, FR-AS-03 and FR-OP-01.
