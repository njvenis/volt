### Independent bounded failure-abort

It records CLOCK_BOOTTIME deadline first_failure+5s, never extends it. This does NOT wait for original broker ordinary-stop deadline, which may never have started.

On that first failure, arm kernel ITIMER_REAL for4.0s with reserved SIGALRM default-fatal disposition; SIGALRM must be unblocked, SIG_DFL and no preexisting timer at runner bootstrap. That gives bounded nonzero termination even if event-loop cleanup or a Python thread/GIL is stuck. Kernel scheduling/freezing is not claimed instantaneous; no process can earn positive authority while frozen. SIGALRM is never converted to clean. Timer remains armed until actual nonzero process exit; do not cancel it in a finally block and then hang in Python finalization. The primitive is internal to the API process, no new inherited channel/service/writer. Delivery/Python3.14 tests must prove thread invocation/blocked-GIL/teardown-hang behavior and no inherited timer conflict; unsupported composition fails startup, not fallback.
